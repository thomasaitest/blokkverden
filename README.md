# Blokkverden

Original voxel-sandkasse i nettleseren (Vite + TypeScript + three.js).
**Ingen** Mojang-/Minecraft-teksturer, lyder, fonter eller logoer — alt er egen pixel-art.

Spill live (etter deploy): https://thomasaitest.github.io/blokkverden/

## Utvikling

```bash
npm install
npm test
npm run dev
```

Bygg for GitHub Pages:

```bash
BASE_PATH=/blokkverden/ npm run build
```

## Kontroller

- **PC:** klikk for pointer lock, WASD, Space hopp, Shift snike, Ctrl/R sprint, 1–9 hotbar, hold venstre for å knuse, høyre for å plassere, F3 debug
- **Nettbrett:** styrespak, dra for å se, knapper for hopp/knus/plasser
